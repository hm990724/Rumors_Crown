## 2. 렌더링 파이프라인 및 단위 규격

- **기본 타일 단위 (Base Grid)**: 1 World Unit = 16 픽셀 ($1\text{m} \times 1\text{m}$)
- **타일 Pixels Per Unit (PPU)**: **`16`** (Filter Mode: Point, Compression: None)
- **몬스터 캐릭터 PPU**: **`32`** (Filter Mode: Point, 월드 크기 0.85~1.0 유닛)
- **카메라 Orthographic Size**: **`4.5f`** (표준 1080p/720p에서 마왕성과 영지가 한눈에 들어오는 최적 화각)
- **카메라 줌 범위**: Min 2.5f (클로즈업) ~ Max 7.5f (원경 조망, 몬스터/건물 식별 한계 보장)
- **Sorting Layers**:
  - `Base Ground`: Order `-100` (기본 잔디 베이스)
  - `Terrain Active`: Order `-95 ~ -90` (흙길, 석판길, 마왕성 바닥)
  - `Environment Props`: Order `-50 ~ 5` (수풀, 잔디 볏, 나무, 벽)
  - `Buildings`: Order `10` (일반 건물) / `15` (마왕성 본관)
  - `Monsters`: Order `20` (배회 몬스터 미니언)
  - `UI Overlay`: Canvas Order `100`

## 3. 외부 타일셋 PNG 교체 아키텍처 및 지원 모드

RUMORS 시스템은 외부 고품질 에셋 팩을 두 가지 방식으로 모두 지원합니다.

### 방식 A: 개별 PNG 파일 드롭인 교체 (Drop-in File Mode)
`Assets/Resources/` 및 `Assets/Art/Sprites/` 내의 해당 경로에 동일한 파일명으로 고품질 PNG를 덮어쓰면 즉시 반영됩니다.

### 방식 B: 단일 스프라이트시트 아틀라스 로딩 (Atlas Spritesheet Mode)
외부 상용 타일셋(예: 128×128, 256×256 크기의 단일 텍스처)을 `Assets/Resources/Tilesets/Terrain_Atlas.png` 경로에 배치하면, [SpriteRegistry.cs](file:///c:/Users/lookm/Documents/GitHub/Rumors_Crown/Assets/Scripts/Core/SpriteRegistry.cs#L80-L115)의 `LoadFromAtlas(atlasPath, tileX, tileY, tileSize)`를 통해 코드 한 줄로 전체 타일맵이 자동 교체됩니다.
