# RUMORS 구현 현황 (정확한 범위)

이 패키지는 **전체 게임 완성본이 아니라, 독립 실행 가능한 시뮬레이션 확장 프로토타입**이다. 원본 저장소의 README만 확인 가능했고 실제 저장소 복제는 네트워크 DNS 문제로 실패했다. 따라서 기존 DemonCastle 씬과의 자동 통합은 하지 않았다.

## 포함
- 60초/일 자동 진행, Space 정지, 1/2/4배속, 10일/월
- 일일 정산은 비차단형 알림이며 일일 결산 모달 없음
- 인간 3명 및 소문 확산도 갱신
- 소문 실체화 테스트 (25 마력 + 신봉자 수 조건)
- 몬스터 5종 기초 스탯, 간이 유전 교배
- 파벌의 불만·집회 및 특수 조건 왕좌 찬탈
- 최초 8일, 이후 7~10일 용사 원정; 간이 전력 비교 결과
- 저장/불러오기 데모, 독립 실험 씬 생성기
- 마왕성 원화 시안, 타이쿤 월드/UI 콘셉트, 독창적인 시계·패널 PNG

## 미포함 / 아직 통합 필요
- 기존 WorldGrid, TimeManager, UIManager와의 실제 통합 (원본 코드 미확보)
- 실제 인간 마을 NPC 이동/렌더링 및 인간 저잣거리 씬
- 모든 신규 건물 및 기술 해금 트리 통합
- 턴/시간에 따른 월드의 실제 작업 애니메이션
- 본격적인 2D 자동전투 AI, 함정, 스킬과 수비 위치
- 유전자 기반 외형 생성·픽셀 편집기 및 정식 가계도 UI
- 파벌 협상 UI 및 시네마틱 왕좌 교체
- 도트 전체 5종 개별 이동/공격 애니메이션 완성

실행 테스트: 해당 환경에 Unity 에디터가 없어 Unity 컴파일 및 Play 모드 검증을 수행하지 못했다.
